# Attribution Taxonomy

## Scope

This skill only explains current short-term abnormal price, limit-up, volume, or capital-flow movements.

Do not:

- Predict future limit-up continuation.
- Provide buy/sell advice.
- Provide position advice.
- Explain long-term industry-chain logic.
- Replace trend analysis.
- Replace strategy selection.

## Allowed Cause Categories

Use only these cause categories:

| Category | Meaning |
| --- | --- |
| 宏观 | Macro data, rates, FX, external macro shocks |
| 行业政策 | Sector policy, regulation, government guidance, industry events |
| 公司公告 | Company announcement, exchange disclosure, IR reply, earnings disclosure |
| 市场情绪 | Hot money sentiment, theme diffusion, short-term attention |
| 美股外盘 | US/HK/global peer movement, futures, overseas sector mapping |
| 资金炒作 | Main capital inflow, block trades, limit-up relay, LHB-style flows |

## Confidence Rules

| Source Type | Confidence |
| --- | --- |
| 交易所公告、公司公告、财报原文、董秘官方回复 | 8-10 |
| 政策原文、权威媒体、行业媒体快讯 | 6-8 |
| 普通财经媒体、券商观点、市场解读 | 5-7 |
| 社区讨论、自媒体小作文、传闻 | 1-4 |
| Only price/capital abnormality, no explicit catalyst | <=5 |

## Cause Count Rules

Each abnormal stock should have at least two possible causes.

If there is no effective catalyst, use these two fallback causes:

1. 纯资金情绪炒作，无基本面 / 政策催化
2. 短线交易拥挤或市场情绪扩散

## Stock-Level vs Global Attribution

Stock-level attribution uses stock code as the main key and explains direct drivers for each stock.

Global attribution uses market theme as the main key and summarizes shared drivers across stocks, industries, concepts, policy events, capital flow, or external market mapping.
