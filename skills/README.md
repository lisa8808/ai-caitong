# Project Skills

Project-local skills are managed here using the standard Skill package structure.

| Skill | Directory | Purpose |
| --- | --- | --- |
| A股异动解读与归因分析 | `abnormal_movement/` | Explains abnormal market/stock movements and attribution. |
| A股自然语言量化选股 | `stock_selection/` | Converts natural-language A-share screening requests into quantitative rules and selected stocks. |
| A股复盘总结 | `review_summary/` | Generates structured market, sector, stock, and operation review reports for PDF archival. |
| A股趋势研判与溯源分析 | `trend_analysis/` | Identifies formed trends, traces root causes, and judges sustainability. |
| A股持仓风控与风险研判 | `risk_control/` | Assesses position risk, rates risk levels, and delivers deterministic hold/reduce/exit advice. |

These skills are product-local modules for AI-conan. They can be promoted to a global OpenCode/Claude skill later if needed.
