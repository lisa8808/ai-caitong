# A股交易技能复盘标准化模板

本模板用于操作复盘、交易复盘、交易技能复盘、能力沉淀和迭代计划。它的目标不是简单描述盈亏，而是把交易结果拆解成可训练、可固化、可淘汰的交易技能。

## 封面信息

```markdown
# A股交易技能复盘报告

**复盘周期**：[用户提供周期；未提供则写“本次交易/本复盘周期未提供”]

**适配交易体系**：[短线波段 / 题材套利 / 趋势持仓 / 用户自定义]

**复盘核心目标**：拆解交易技能优劣、量化能力短板、固化高阶盈利技能、淘汰错误交易习惯、形成可迭代的标准化交易动作

**复盘人**：[用户提供；未提供则写“未提供”]

**复盘日期**：[当前日期]
```

## 一、周期交易数据总览（技能结果量化）

目的：用客观数据反映交易技能落地效果，摒弃主观感受，量化能力盈亏。

必须覆盖：

1. 账户核心数据：期初资金、期末资金、当期盈亏、收益率、相对沪深300超额收益。
2. 交易行为数据：总交易笔数、盈利笔数、亏损笔数、整体胜率。
3. 风控波动数据：账户最大回撤、单笔最大盈利、单笔最大亏损、平均盈亏比。
4. 交易效率数据：空仓天数、频繁交易天数、体系内合规交易占比、情绪化违规交易占比。

数据缺失时使用“未提供/待补充”，不要编造。

## 二、当期市场认知技能复盘（底层研判能力）

核心复盘：对大盘周期、题材主线、资金情绪的研判技能是否精准。

### 1. 大盘周期研判技能

- 当期大盘周期定义：强势上行 / 震荡结构性行情 / 弱势退潮 / 极致混沌。
- 个人研判结果。
- 研判偏差分析：精准 / 小幅偏差 / 严重误判，并说明具体偏差，例如误将震荡行情判断为趋势行情、无视指数破位风险、错判量能趋势。

### 2. 题材主线甄别技能

- 市场真实主线、支线、退潮题材。
- 个人题材取舍动作。
- 技能优劣总结：是否具备主线聚焦能力、是否杜绝杂毛题材炒作、能否识别题材持续性。

### 3. 市场情绪解读技能

- 核心情绪指标：连板高度、炸板率、涨跌家数、资金流向。
- 个人情绪应对策略。
- 技能短板：是否存在情绪高位激进、情绪低位恐慌、混沌行情盲目出手。

## 三、单笔交易技能拆解（核心落地复盘）

核心逻辑：不单纯复盘盈亏，重点拆解选股、择时、仓位、入场、持仓、止盈止损六大交易技能，区分“运气盈利”和“能力盈利”、“认知亏损”和“操作失误亏损”。

### （一）盈利交易｜正向技能固化

对每笔盈利交易覆盖：

- 标的名称 + 代码。
- 选股技能：选股逻辑、选股依据、合规点。
- 择时技能：入场节点、出场节点、优势点。
- 仓位技能：仓位配比是否匹配行情确定性。
- 操作纪律：是否严格执行体系规则、是否无情绪化操作。
- 核心可复用技能：重点沉淀成可复用动作。
- 可优化细节。

### （二）亏损交易｜负向技能纠错

对每笔亏损交易覆盖：

- 标的名称 + 代码。
- 亏损根源技能定位：认知研判失误 / 选股技能缺陷 / 择时能力不足 / 仓位管理失控 / 纪律执行失效 / 情绪化操作。
- 认知层面：是否错判市场周期、题材强度、资金情绪。
- 选股层面：是否非主流杂毛、无板块联动、无资金抱团、逻辑不支撑。
- 择时层面：是否逆势操作、高位追涨、节点踏错。
- 仓位层面：是否重仓试错、亏损加仓、仓位与确定性不匹配。
- 纪律层面：是否破位不止损、盈利不止盈、侥幸扛单、频繁换股。
- 对应技能整改方向。

### （三）踏空/观望交易｜机会判断技能复盘

- 当期确定性优质机会。
- 踏空核心原因：主线识别滞后 / 龙头辨识度不足 / 恐高心理 / 持仓分散 / 等待过度。
- 机会取舍技能优化。

## 四、个人交易技能短板汇总（系统性问题沉淀）

聚焦可精准改进的技能缺陷，拒绝空泛总结。

必须覆盖：

1. 市场研判技能短板。
2. 选股筛选技能短板。
3. 买卖择时技能短板。
4. 仓位管理技能短板。
5. 风控纪律技能短板。
6. 心态执行技能短板。

## 五、当期成熟盈利技能固化（标准化动作沉淀）

把当期验证有效的交易技能固化为个人标准化交易动作 SOP。

必须覆盖：

1. 行情适配技能：何种市场环境可重仓、轻仓、空仓。
2. 选股标准化技能：主线优先、龙头优先、联动优先，剔除标的标准。
3. 入场标准化技能：固定低吸/突破入场形态、指标、量能条件。
4. 持仓标准化技能：持仓观察核心指标、板块联动跟踪规则、动态调仓条件。
5. 止盈止损标准化技能：支撑压力位止盈止损、分批操作规则、极端行情应对动作。

## 六、下期技能迭代计划（精准提升方案）

原则：一期优化 1-2 项核心技能，不贪多，稳迭代。

必须覆盖：

1. 重点提升核心技能：列出优先级最高的 1-2 个技能。
2. 具体训练落地方法：例如每日复盘主线题材强度、杜绝杂毛选股、严格执行止损纪律。
3. 新增交易技能规则：选股、择时、风控、仓位各 1 条。
4. 禁止性交易红线：至少 3 条。
5. 下期量化考核指标：合规交易占比、情绪化交易次数、单笔亏损上限、整体盈亏比。

## 七、技能成长总结与认知迭代

必须覆盖：

1. 当期交易核心成长：技能层面的进步，非盈亏结果。
2. 最致命的能力漏洞：长期影响复利的核心问题。
3. 交易认知升级：对市场、交易体系、自身能力的新认知。
4. 长期技能迭代核心方向：聚焦机械化、标准化、纪律化交易，弱化主观情绪，依靠可复制的交易技能实现稳定复利。

## 输出要求

- 保留七大章节顺序。
- 精确数据缺失时不要编造，用“未提供/待补充”。
- 每个结论都尽量落到“技能问题、技能优势、下一步动作”。
- 报告末尾加入：本文仅基于用户提供的信息整理，用于复盘学习和流程优化，不构成投资建议。
