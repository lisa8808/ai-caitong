# 复盘总结 PDF Skill

使用本技能把用户提供的行情、板块、个股、交易记录或聊天摘要整理为结构化复盘报告，并尽量生成 PDF 文件。报告用于投研归档和交易改进，因此要兼顾数据清晰、逻辑可追溯、结论可执行。

## 工作流程

1. 判断复盘类型：`板块热点`、`市场复盘`、`个股复盘`、`操作复盘`、`交易技能复盘`，或综合复盘。
2. 提取用户提供的数据：指数、涨跌幅、成交额、资金流、板块、个股、买卖点、仓位、收益、原因说明。
3. 如果关键数据缺失，继续生成报告，但在对应章节标注“数据缺失”或“基于用户提供信息整理”，不要编造精确行情数据。
4. 按复盘类型选择模板。需要模板细节时读取 `references/report_templates.md`；当用户要求操作复盘、交易复盘、技能复盘、能力沉淀或迭代计划时，优先读取并套用 `references/trading_skill_review_template.md`。
5. 先生成 Markdown 正文，再调用 `scripts/render_pdf.py` 输出 HTML/PDF。
6. 在最终回复中给出生成文件路径，并简要说明报告覆盖了哪些章节。

## 报告风格

- `板块热点`：偏投研归档，突出主线、龙头、资金、持续性。
- `市场复盘`：偏投研归档，突出指数、成交、资金、情绪、风险。
- `个股复盘`：投研与交易观察结合，突出涨跌原因、形态、资金、观察点。
- `操作复盘` / `交易技能复盘`：偏实战复盘和能力沉淀，按“周期交易数据总览 -> 市场认知技能 -> 单笔交易技能拆解 -> 技能短板 -> 成熟盈利技能固化 -> 下期技能迭代计划 -> 技能成长总结”展开。

用户指定风格时，以用户指定为准。用户未指定时，按上面的默认风格。

## 输出结构

Markdown 报告建议使用以下结构：

```markdown
# [复盘类型]报告 - [日期]

## 一、核心结论
- [3-5 条结论]

## 二、关键数据
| 指标 | 数据 | 解读 |
| --- | --- | --- |

## 三、复盘分析
[根据类型展开]

## 四、风险与明日观察
- [风险]
- [观察点]

## 五、行动建议
- [可执行建议]

## 免责声明
本文仅基于用户提供的信息整理，不构成投资建议。
```

## PDF 生成

使用脚本：

```bash
python scripts/render_pdf.py --title "市场复盘报告" --input report.md --output-dir ./outputs
```

脚本会优先输出 HTML，并在可用时生成 PDF。若本地缺少 PDF 依赖或浏览器环境，保留 HTML 文件作为可打印版本，用户可用浏览器打开后保存为 PDF。

## 数据原则

- 不要把模型推断伪装成事实数据。
- 对精确数值保持来源意识：用户给了就引用；没给就写“未提供”。
- 可以给出逻辑判断和观察方向，但要说明依据。
- 操作复盘要避免事后诸葛亮，只评价流程、纪律、风险收益比和执行一致性。
- 交易技能复盘要把“盈亏结果”拆成可训练的技能项，区分运气盈利、能力盈利、认知亏损和操作失误亏损。
- 模板中用户未提供的数据字段保留为“未提供/待补充”，不要用估算值填充期初资金、收益率、胜率、最大回撤、交易笔数等精确指标。

## 最终回复

最终回复要简洁，包括：

- 报告已生成。
- Markdown/HTML/PDF 文件路径。
- 如果 PDF 未生成，说明已生成可打印 HTML。
- 简述包含的复盘类型和章节。
